# TarsosDSP JAR Files

## Required JAR Files

Please download the following JAR files from the TarsosDSP GitHub releases and place them in this directory:

1. **TarsosDSP-core-2.4.jar**
2. **TarsosDSP-jvm-2.4.jar**

## Download Instructions

1. Go to: https://github.com/JorenSix/TarsosDSP/releases/tag/release-2.4
2. Download the JAR files listed above
3. Place them in this `app/libs/` directory
4. Sync your Gradle project

## Alternative: Direct Download Links

If the GitHub releases page doesn't work, you can try:
- Maven Central: https://repo1.maven.org/maven2/be/tarsos/dsp/
- Or build from source: https://github.com/JorenSix/TarsosDSP

## Verification

After adding the JARs, the build should succeed. The JARs will be automatically included in your project.
